# Bangla terminology, settled

The Bangla side of this site was written by more than one hand. This file is what stops it
drifting apart again. If a `bn.ts` file disagrees with this table, the table wins; if the table
is wrong, change it here first and then change every page in the same commit.

The notes are in English because they are enforcement instructions for whoever is holding the
two languages in step, not copy. Everything in the second column is copy.

## 3. What stays in Latin, and how it is wrapped

Latin inside a Bangla sentence takes `<span class="latin" lang="en">…</span>` in any field the
template renders with `set:html`. The class is not decoration: `base.css` uses it to switch to
the Latin face and undo the Bangla size and tracking, and `lang="en"` is what a screen reader
needs to stop pronouncing the run as Bangla.

- **Wrapped, with `lang="en"`.** Product, API, format and file names: iOS, iPadOS, macOS,
  Xcode, XcodeGen, InputMethodKit, Core Haptics, Core ML, ONNX, WebAssembly, GitHub, README,
  FST, CLDR, IME, C ABI, JNI, TSF, IBus, Fcitx5, X11, Wayland, ZWNJ, ASCII, SDK, HTTP, UTF-8,
  n-gram, EPUB, OCR, Git LFS, OmicronLab, OpenBangla, iAvro, Lekho, and any literal string the
  interface shows in English (`Get Started`, `Allow`, `Copy Build Details`). Two names go the
  other way and are written in Bangla script instead: অভ্র কীবোর্ড and অভ্র ফোনেটিক.
- **Wrapped, without `lang`.** Bare figures a reader copies or checks against a file:
  `845,461`, `1,776`, `0.9.3`, `8.8 MB`, `29 MB`, `390 KB`, `500`, `32`, `73`. They are read as
  numbers in whatever language the page is in, so marking them English would make a screen
  reader spell them out in the wrong one. The two artifact sizes are decimal MB and the WASM
  figure is the file this site serves, `public/wasm/obadh_engine_bg.wasm`; the engine README's
  Performance Snapshot still says 280 KB, which is three minor releases stale.
- **Not wrapped at all.** Roman input to the engine, which is `<code>` and nothing else, the
  mono face carries no Bengali, and `.latin` on top of it would fight the code styling.
- **Not wrapped, because it cannot be.** `requirement`, `action.label`, `action.note`,
  `PlatformRow.name`/`.line`/`.stateLabel`, `Composer`'s `hint`, `caption` and `noscript`, and
  `ogImageAlt` are rendered as plain text, not `set:html`. Markup in them ships as visible
  angle brackets. Latin runs in those fields stay bare; keep them short. On the home page
  only `features.items[].body` and `avro.body[]` take `set:html`, every heading and lede
  there is plain text, which is why `845,461` sits bare in `open.lede`.
- **Single Roman letters in a scheme-table note** stay bare, matching the English note column
  they sit beside in `src/data/scheme.ts`.

**Platform names take Bangla; operating systems keep their identifier.** আইফোন, আইপ্যাড, ম্যাক,
লিনাক্স, অ্যান্ড্রয়েড, উইন্ডোজ, ক্রোমওএস, but `iOS 18`, `iPadOS 18`, `macOS 15`. অ্যাপ স্টোর,
প্লে স্টোর and ডিসকর্ড are Bangla; they are places people talk about, not identifiers.

**Headings and FAQ questions are spoken sentences**, so an English term inside one is written in
Bangla script and carries no markup: আইওএসে ফুল অ্যাক্সেস কী করে, ম্যাকে বাংলা. In body prose the
same term is the Latin identifier in its span. The FAQ questions are also the `name` values in
the FAQPage structured data, which is a second reason they stay clean.

## 4. Register

- **আপনি throughout**, on every page, including imperatives: লিখুন, দেখুন, খুলুন, বেছে নিন.
- **People get the honorific**: তিনি, তাঁরা, যাঁরা, লিখেছেন, বলেন. That includes the reader,
  the four people behind Avro, contributors, and whoever builds Obadh. মানুষ as an indefinite
  general subject keeps the plain verb (মানুষ লেখে, মানুষ যা বলে) but a definite group of
  people takes the honorific, including the readers of Bangla themselves.
- **One anchor text per page, and the anchor carries পাতা.** The genitive form goes inside the
  link, the way the English side puts "page" inside it: ডাউনলোডের পাতায়, লেখার নিয়মের পাতায়,
  পরিচিতির পাতায়, প্রশ্ন-উত্তরের পাতায়, অবদানের পাতায়, গোপনীয়তার পাতায়. A link to a section
  carries that section's own words instead, and the page's full title is used only where the
  whole page is the destination, as in the `link` fields on the home page.
- **No exclamation marks, no emoji** except the ❤️ in the emoji sentence, which is the feature.
- **দাঁড়ি, not a full stop**, at the end of every Bangla sentence. A Latin abbreviation or
  version number at the end of a sentence still takes দাঁড়ি after it.
- **Bangla numerals in prose** (চৌদ্দটি প্রশ্ন, ২৪ কোটি ২০ লাখ, ২০০৩ সালের ২৬ মার্চ, ৳৫০০).
  Latin digits only for versions, sizes, thresholds and measurements, per §3.
- **Say less than the English where Bangla already carries it.** A gloss that tells a Bangla
  reader what অবাধ, বই or ভালোবাসা means is an insult with good manners; the English pages
  gloss because they must. `content-index.md` §9 lists the passages this applies to.
